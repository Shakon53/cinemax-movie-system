# В публичном каталоге только полные фильмы

По запросу владельца 32 карточки без полного фильма сняты с публикации. Их строки сохранены как черновики, поэтому связи отзывов, избранного и личного дневника не удаляются. Через публичный Data API эти карточки больше не читаются; интерфейс каталога фильтрует `published=true` также для администратора. Административная таблица черновиков доступна по прежним правилам.

Добавлены три полных фильма с настоящими локальными JPG-обложками с официальных страниц Мосфильма:

- [Любовь в СССР (2012)](https://www.mosfilm.ru/cinema/films/lyubov-v-sssr/) — русский, полный RuTube-плеер с официальной страницы, около 90 минут.
- [Палата №6 (2009)](https://www.mosfilm.ru/cinema/films/palata-6/) — русский, полный RuTube-плеер с официальной страницы, около 87 минут. Режиссёры Карен Шахназаров и Александр Горновский указаны в описании; схема каталога хранит одного основного режиссёра.
- [Белый Тигр (2012)](https://www.mosfilm.ru/cinema/films/belyy-tigr/) — русский, полный YouTube-плеер официального канала Мосфильма, около 109 минут. Проверены статус `OK` и разрешённое встраивание.

Для RuTube проверены название, длительность и отсутствие удаления в API. Отзывы и оценки не выдумывались. Источники Summoners и On the Line исключены: проверка YouTube вернула `UNPLAYABLE`. Четыре существовавшие русские YouTube-версии повторно проверены: доступны и разрешают встраивание.

Миграция `202610190012_full_movies_only.sql` добавляет фильмы без дублей, восстанавливает отсутствующие обложки открытых фильмов Blender из официальных thumbnails, затем скрывает карточки без полного источника. CHECK `movies_published_full_movie` запрещает публиковать карточку без обложки, признака бесплатного просмотра и поддерживаемой ссылки на полный плеер. Он проверяет структуру ссылки, а не постоянную доступность внешнего видеосервиса.

После миграции публичный каталог содержит 21 фильм с полным просмотром: 17 полнометражных и четыре короткометражных Blender. Язык указан в карточках; три зарубежных фильма 2023–2024 годов остаются на английском. Порядок 11 закреплённых владельцем карточек сохраняется.

27 тестов проверяют миграции, повторное применение, публичное скрытие трейлерных карточек, запрет их повторной публикации без полного источника, защиту дневника и фильтрацию каталога до пагинации. Полное воспроизведение каждого видео от начала до конца не проверялось; доступность зависит от сервиса и региона.
