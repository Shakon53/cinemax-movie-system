- [Любовь и голуби](https://www.mosfilm.ru/cinema/films/lyubov-i-golubi/)

Плееры взяты из раздела «Смотреть фильм» на официальных страницах Мосфильма, а не из блока трейлера. Используются встроенные RuTube-плееры. Права сохраняются за правообладателем; фильм не копируется в Supabase Storage. Постеры взяты с тех же страниц. В карточке сохранены ссылка на правообладателя, атрибуция, язык и актёры. Оценка 0 означает отсутствие оценок CineMax.

Миграция `202610190008_official_full_movies.sql` добавляет записи без повторных копий. Она допускает локальные JPG-постеры и сохраняет остальные проверки URL. После применения каталог содержит 41 опубликованную запись, девять с полным просмотром (пять полнометражных и четыре короткометражных Blender).

Длительность карточек соответствует округлённой длительности выбранного видео, включая заставки. Перед публикацией проверены ответы API RuTube: названия соответствуют фильмам, длительность 82–105 минут, видео не удалены. Реальное воспроизведение в браузере пользователя не проверено. Доступность и реклама зависят от видеосервиса и региона; при ошибке можно открыть официальную страницу и выбрать другой плеер.

Frontend принимает только HTTPS, точные домены и ожидаемые пути плееров. Параметры URL отбрасываются; поддельные домены, пользователь/пароль в адресе и нестандартные порты не допускаются. Проверки PostgreSQL выполняют миграцию дважды и проверяют количество фильмов.
