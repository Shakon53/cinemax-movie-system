About the Project

CineMax is a full-stack Movie Management System built as a graduation/course project. It allows users to browse movies, read and write reviews, explore actors and directors, and manage content through an admin panel.

Backend
  • ASP.NET Core 8 Web API
  • Entity Framework Core
  • PostgreSQL (Supabase)
  • REST API + Swagger
  • Docker + Render hosting
Frontend
  • HTML5 + CSS3
  • Bootstrap 5
  • Vanilla JavaScript
  • TMDB Posters + YouTube Trailers
  • Netlify hosting
